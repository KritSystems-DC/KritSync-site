Current conclusion:
- The local release package passes basic structure/config/static checks.
- No Defender detections were reported.
- Static checks strongly indicate that the bundled Poco/OpenSSL/minizip/z DLLs
  are not required by Krit-Faslo.dll.
- The main residual risks are unsigned DLLs and untested runtime behavior on an
  actual ASA/ArkServerAPI server.
