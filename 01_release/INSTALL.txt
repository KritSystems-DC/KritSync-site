Krit-Faslo Installation
=======================

Copy this folder:

  Krit-Faslo/

Into:

  ShooterGame/Binaries/Win64/ArkApi/Plugins/

Final path should be:

  ShooterGame/Binaries/Win64/ArkApi/Plugins/Krit-Faslo/

Expected contents:

  Krit-Faslo.dll
  config.json
  README.md
  CONFIG-COMMENTED.jsonc

Important:

- Do not rename the Krit-Faslo folder.
- Do not rename Krit-Faslo.dll.
- ArkServerAPI / ASA Server API expects the plugin folder and main DLL names to
  match.
- AsaApi.dll must be supplied by the server's ArkServerAPI / ASA Server API
  installation.
- Paste an issued license into LicenseKey in config.json. Without a valid key,
  this licensed build logs a rejection and disables plugin behavior.
- CONFIG-COMMENTED.jsonc is documentation only. Keep config.json as valid JSON.
- Test on a spare/local server before deploying to a live server.

Admin-only license files:

- The workspace 03_license_admin folder is for the plugin owner only.
- Do not copy 03_license_admin or krit-faslo-private-key.json to the game server.
